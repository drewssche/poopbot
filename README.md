# Poopbot

Poopbot — Telegram-бот для ежедневного трекера «походов» в чатах: вопросы, напоминания, статистика и периодические итоги.

## Что умеет

- Публикует Q1 (основной вопрос) в выбранное время чата.
- Ведет счетчик `+💩 / -💩` по участникам за текущую сессию.
- Поддерживает уточняющие вопросы Q2/Q3:
  - автопост (если включен),
  - ручной вызов кнопкой `🧻 Уточняющие вопросы` в Q1 (если автопост выключен).
- Отправляет напоминания:
  - финалка 23:30 (отдельный переключатель).
- Закрывает сессию в 23:55.
- Отправляет периодические итоги в 23:50:
  - неделя (воскресенье),
  - месяц (последний день месяца),
  - год (31 декабря).
- В периодических итогах показывает:
  - срез за реальный период,
  - тенденцию к прошлому периоду,
  - для групп — место чата среди чатов и динамику места.

## Команды

- `/start` — активировать/показать актуальный Q1.
- `/help` — помощь и настройки.
- `/stats` — статистика (`Моя`, `В этом чате/личке`, `Среди чатов`, `Глобальная`).
- `/debug` — меню отладки для владельца бота (owner-only).

## Настройки

В `/help` -> `Настройки`:

- `🔔 Уведомления` — общий переключатель плановых сообщений.
- `⏳ Финалка 23:30` — отдельный `Вкл/Выкл`.
- `🧻 Q2-Q3` — отдельный `Вкл/Выкл`.
- Время автопоста Q1: `10:00`, `14:00`, `19:00`.
- `👁️ Видимость чата в рейтингах` (для групп).
- Удаление данных:
  - `🗑️ Удалить меня`,
  - `🧹 Удалить меня из этого чата`.

## Debug (для владельца)

`/debug` открывает админ-меню с режимами:

- `Режим: Превью` — показывает, как будет выглядеть сообщение.
- `Режим: Отправка` — реально отправляет сообщение в чат.
- `🔄 Обновить меню` — обновляет экран debug-меню и текущий статус.

Доступны тесты Q1/Q2/Q3, напоминаний, периодических итогов, holiday-сообщений и рекапов, плюс `Прогнать все`.
В меню показывается последнее debug-действие: кто, что, режим и время.
Под каждым отправленным debug-сообщением есть кнопка `ℹ️ Как это работает` с пояснением условий срабатывания.

## Требования

- Docker
- Docker Compose

## Переменные окружения

Создай `.env` на основе `.env.example`:

```env
BOT_TOKEN=...
POSTGRES_DB=poopbot
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_HOST=db
POSTGRES_PORT=5432
DATABASE_URL=postgresql+psycopg://postgres:postgres@db:5432/poopbot
```

## Запуск

```bash
docker compose up -d --build
```

## Логи

```bash
docker compose logs -f --tail=200 bot
```

PowerShell:

```powershell
docker compose logs -f --tail=200 bot | Select-String -Pattern "ERROR|Traceback|Update id="
```

## Важно

- Миграции применяются при старте контейнера бота.
- Часовой пояс и время автопоста настраиваются отдельно для каждого чата.
- Таймзона по умолчанию: `Europe/Minsk`.
