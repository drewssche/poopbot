### 2. Проценты >100% в "Моя статистика"

**Проблема:**
```
🌙 Ночь: 32 раз (76%)
🌅 Утро: 49 раз (117%) ← ❌
☀️ День: 75 раз (179%) ← ❌
🌆 Вечер: 57 раз (136%) ← ❌
```

**Причина:** Проценты считаются от `total_poops` (дедуплицировано), а не от суммы слотов.

**Решение:**
```python
# Сейчас:
slot_total = total_poops  # ❌

# Надо:
slot_total = sum(slot_counts.values())  # ✅
pct = (count / slot_total * 100)
```

**Файлы:**
- `app/services/stats_service.py` — `_format_slot_patterns()`

**Проблема:** Не видно, какое место занимает пользователь.

**Решение:** Показывать место:
```
🏆 Титулы месяца:
🌙 Ночной серун — ТЫ (#1) — 32 ночных похода 👑
🌅 Утренний жаворонок — #3 — 51 утренний поход
☀️  Дневной трудяга — ТЫ (#1) — 75 дневных походов 👑
🌆 Вечерний философ — ТЫ (#1) — 57 вечерних походов 👑
```

**Файлы:**
- `app/services/stats_service.py` — `build_stats_text_global()`

### 4. Нет паттернов в "В этой личке"

**Решение:** Добавить блок паттернов (как в "Моя статистика"):
```
💬 В этой личке
Период: за месяц (01.03.25–31.03.25)

Твои итоги:
- Всего: 💩(8)
- Дней с 💩: 6/31

🕐 Твои паттерны:
🌙 Ночь (00–06):   0 раз  (0%)
🌅 Утро (06–12):   5 раз  (63%) ← Пик!
☀️  День (12–18):  2 раза (25%)
🌆 Вечер (18–24):  1 раз  (13%)

💡 Титул: «Утренний жаворонок» 🌅
...
```

**Файлы:**
- `app/services/stats_service.py` — `build_stats_text_chat()` (блок для private chat)
