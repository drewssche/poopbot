# Пилот ежедневного виджета

Ежедневный Q1 меняет формат только при совпадении ID пилотной группы и значения
`app_settings.group_daily_widget_pilot`. Для включения после обновления контейнера:
`docker compose exec -T bot python -m scripts.enable_group_widget`.
Команда проверяет активную сессию, публикует новый вопрос, переключает её Q1
и только после коммита удаляет предыдущий вопрос. Повторный запуск в той же сессии
не рассылает дубликаты. Архивные опросы и отчёты остаются в прежнем формате.

Счётчик и календарь — количество событий группы. Персональные ответы и выбор
уточнений доступны только на устройстве нажавшего. Повтор запроса использует
тот же ключ операции. Из пересланной копии отметить день нельзя.
Записи outbox с префиксом `widget:q1:` адресуют виджет по существующему полю
`photo_message_id`; фоновый обработчик отправляет только состояние. При
проверке доставки сравнивают `revision` с `delivered_revision`, а календарь —
с событиями, для которых исходный чат совпадает с чатом сессии.

Сброс настройки отключает действия пилота и возвращает прежний формат для
новых вопросов; уже отправленное сообщение от этого не становится фотографией.
