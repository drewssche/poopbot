# Metrics Semantics

Дата актуализации: 2026-02-16

## Базовые сущности

- `SessionUserState`:
  - дневной факт активности пользователя в конкретной сессии чата (`poops_n`),
  - используется для стриков по сессиям и межчатовых сумм `poops_n`.
- `PoopEvent`:
  - детальные события походов внутри дня (`event_n`, `origin_chat_id`, bristol/feeling),
  - используется для распределений, где важна именно детальность и происхождение события.

## Стрики

- `Чатовый стрик`:
  - считается по `SessionUserState.poops_n > 0` в рамках `chat_id` по датам сессий.
  - синхронизированные отметки между чатами входят в чатовый стрик.
- `Глобальный стрик`:
  - считается по `SessionUserState.poops_n > 0` по всем чатам пользователя.
  - день активен, если хотя бы в одной сессии любого чата есть `poops_n > 0`.

## /stats

- `🙋 Моя`:
  - итоги: дедуп по дням между чатами (`max(poops_n)` на `(user, day)`),
  - стрики: глобальные по `SessionUserState`.
- `💬 В этой личке`:
  - итоги и стрики считаются по локальным `PoopEvent` этой лички (`origin_chat_id == chat_id`) для консистентности блока.
- `👥 В этом чате`:
  - итоги/распределения: по `PoopEvent` этого чата (`origin_chat_id == chat_id`),
  - стрики: по `SessionUserState` этого чата (включая синк).
- `🌍 Глобальная`:
  - итоги: дедуп по дням между чатами (`max(poops_n)` на `(user, day)`),
  - глобальные стрики: по `SessionUserState` по всем чатам.
- `🏟️ Среди чатов`:
  - `Топ по общему количеству`: `sum(SessionUserState.poops_n)` по сессиям чата,
  - `Топ по среднему на участника`: total / число уникальных пользователей с `poops_n > 0`,
  - `Топ по стрику чата`: максимум чатового стрика участников (по `SessionUserState`),
  - `Рекорд дня`: максимум дневной суммы `sum(poops_n)`; при ничьей выводятся все чаты-победители.

## Период "за всё время"

- Старт диапазона: минимальная дата в `sessions` (дата старта данных бота).
- Для чата: минимальная дата `sessions` именно этого `chat_id`.

## Debug

- `/debug -> Stats raw` показывает:
  - origin-дни (`PoopEvent` с `origin_chat_id == chat_id`),
  - chat-state дни (`SessionUserState` в чате),
  - global-state дни (`SessionUserState` по всем чатам),
  - текущий/лучший стрик по каждому набору.
