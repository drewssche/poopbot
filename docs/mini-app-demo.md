# PoopCheck: интерактивный макет на демоданных

Исходник: https://www.figma.com/design/WRKqMhlFx8pJjegt5jVhZg/Untitled?node-id=0-1
За основу взят нижний ряд четырёх экранов: main screen 1, main screen 2,
calendar screen, statistics screen. Сохраняются расположение элементов,
светлая палитра, круглая кнопка `+`, подписи и структура. Системные часы и
полоса iPhone не дублируются: их рисует устройство/Telegram. Статический
логотип воспроизведён SVG; оригинал и точные шрифты можно подставить после
экспорта из Figma. Никаких новых экранов настроек/контекстов в демо нет.

## Как попробовать

На владельца бота настраивается персональная кнопка меню «Прототип» с URL
https://financeweaselapp.duckdns.org/poopcheck-demo/.
Меню остальных пользователей не меняется. Внешний браузер также подходит
для проверки макета; Telegram SDK необязателен для работы демо.

- `+` начинает ввод записи для выбранного дня: консистенция → ощущения.
  Выбор ощущения сохраняет запись и открывает календарь. Можно начать
  выбор консистенции сразу на первом экране, не нажимая `+`.
- Нажатие на название месяца открывает календарь. Стрелки листают месяцы;
  нажатие на название месяца в календаре возвращает к недельному виду.
- Дни выбираются нажатием. Значок графика открывает статистику.
- Карандаш открывает редактирование. Свайп записи влево открывает корзину.
  Клавиатурный эквивалент: фокус на карандаше → стрелка влево.
- Значок меню возвращает на главный экран; новый дизайн меню не добавлен.
- Кнопка «Назад» в Telegram возвращает на предыдущий этап.

Демо-дата фиксирована: **23 июня 2026**, как в макете. Исходные 196 записей
дают лучшую серию 42 дня и текущую серию 24 дня. Все счётчики пересчитываются
из демонстрационных записей. Изменения хранятся только в localStorage по
ключу `poopcheck.design-demo.v1`. Если хранилище недоступно, работа продолжается
в памяти до закрытия. Сброс — удаление именно этого ключа, не всего хранилища.
Фактическое время нового ввода берётся с устройства; дата остаётся выбранной.

## Изоляция

Это статические HTML/CSS/JS. Они не читают initData/профиль Telegram,
не обращаются к API бота или базе, не отправляют сообщения, не запускают
планировщики. На сервере нет нового процесса/контейнера: файлы отдаёт Nginx.
`connect-src 'none'` запрещает сетевые API-запросы из демо. Скрипт Telegram
разрешён отдельно для расширения окна, безопасных отступов и кнопки «Назад».
Демо общедоступно по URL и содержит только вымышленные записи.
Это не авторизация для будущего рабочего Mini App — её нужно реализовать отдельно.

## Развёртывание

Публикация: GitHub `main` → `/opt/poopbot` через `git pull --ff-only origin main`.
Подключить `deploy/nginx/poopcheck-demo.conf` внутри HTTPS server-блока
существующего домена; предварительно сохранить копию конфигурации,
выполнить `nginx -t`, затем `systemctl reload nginx`. Новая location не меняет
обработку `/` у ФинАсиста. Бот и БД не требуют перезапуска.

Настройка персонального меню выполняется Bot API `setChatMenuButton` с
`chat_id=BOT_OWNER_ID` и `menu_button.type=web_app`. Перед настройкой сохранить
ответ `getChatMenuButton` в закрытом локальном каталоге резервных копий.
Откат: восстановить это меню и убрать только include из HTTPS server-блока,
проверить конфигурацию и перезагрузить Nginx.

Локальная проверка: `python3 -m http.server 8765 --bind 127.0.0.1 --directory web/demo`.
Проверка данных: `node --test tests/demo_model.test.cjs`.
