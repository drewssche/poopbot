# Сравнения массы с животными

В недельной, месячной и годовой карточках выводятся расчётная масса, вода на смыв
и шуточный эквивалент массы с силуэтом. Дневной вопрос остаётся невысоким.
Вода — `#3DA5FF`, остальные цвета и шрифты сохранены. Пустой отчёт не показывает
животное. Реальные отметки не меняются: используется прежняя оценка 150 г на отметку.

Выбирается ближайший по отношению масс ориентир, число животных округляется до
десятых. Дробные значения допустимы: 3,15 кг ≈ 0,7 кошки. На карточке явно указан
принятый вес животного; это иллюстрация, не утверждение о весе каждого животного.

Округлённые ориентиры:

| Животное | Ориентир | Источник |
|---|---|---|
| Голубь | 0,35 кг | [Animal Diversity Web](https://animaldiversity.org/accounts/Columba_livia/), 358,7 г |
| Кошка | 4,5 кг | [Animal Diversity Web](https://animaldiversity.org/accounts/Felis_catus/), 4,1–5,4 кг |
| Лабрадор | 30 кг | [AKC, стандарт породы](https://images.akc.org/pdf/breeds/standards/LabradorRetriever.pdf), 55–80 фунтов в зависимости от пола |
| Лошадь | 450 кг | [University of Michigan, BioKIDS](https://biokids.umich.edu/critters/Equus_caballus/), 227–900 кг в зависимости от породы |
| Бегемот | 1500 кг | [San Diego Zoo Wildlife Alliance, справочник](https://ielc.libguides.com/sdzg/factsheets/hippopotamus/summary), средние 1385/1546 кг по полу |

Силуэты `dove`, `cat`, `dog`, `horse`, `hippo`: **Font Awesome Free 6.7.2**,
Fonticons, Inc., [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
[Оригиналы](https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs/solid)
сохранены в `app/assets/reports/animal-sources/` вместе с лицензией. Изменения:
цвет `#934c21`, преобразование в PNG и масштабирование. Иконки условные;
например, силуэт `dog` используется для ориентира «лабрадор».

PNG подготовлены заранее. На VPS нет новых зависимостей или сетевых обращений
для рендера. Код сравнения и PNG включены в отпечаток рендера для обновления
кеша; опубликованные карточки обновятся при следующем изменении их данных.
